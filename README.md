# Restaurant Menu Application

## Overview

Restaurant Menu Application เป็นแอปพลิเคชัน Android สำหรับจัดการรายการอาหาร โดยผู้ใช้สามารถเพิ่ม แก้ไข ลบ และค้นหารายการอาหารได้ผ่านอุปกรณ์ Android

โปรเจกต์นี้พัฒนาด้วย **Android Studio** โดยใช้ภาษา **Java** และเชื่อมต่อกับ **Firebase** เพื่อจัดเก็บข้อมูลแบบออนไลน์ ทำให้สามารถจัดการข้อมูลได้สะดวกและรองรับการอัปเดตข้อมูลแบบ Real-time

---

## Features

* แสดงรายการอาหาร
* เพิ่มเมนูอาหาร
* แก้ไขข้อมูลเมนู
* ลบเมนูอาหาร
* ค้นหาเมนูอาหาร
* แสดงรายละเอียดของเมนูอาหาร
* บันทึกข้อมูลบน Firebase

---

## Technologies Used

* Android Studio
* Java
* Firebase Firestore / Realtime Database
* Firebase Authentication (หากมี)
* XML (User Interface)
* Material Design Components

---

## Database

ระบบใช้ Firebase สำหรับจัดเก็บข้อมูลเมนูอาหาร โดยข้อมูลที่บันทึกประกอบด้วย

* ชื่อเมนู
* รายละเอียด
* ราคา
* ประเภทอาหาร (ถ้ามี)
* รูปภาพเมนู (ถ้ามี)

---

## Workflow

1. เปิดแอปพลิเคชัน
2. แสดงรายการเมนูอาหารทั้งหมด
3. เพิ่มเมนูอาหารใหม่
4. แก้ไขข้อมูลเมนู
5. ลบเมนูอาหาร
6. ค้นหาเมนูอาหาร
7. บันทึกและอัปเดตข้อมูลบน Firebase

## Purpose

* ศึกษาการพัฒนา Android Application
* ฝึกใช้งาน Android Studio ด้วยภาษา Java
